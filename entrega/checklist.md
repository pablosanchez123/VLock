# Checklist de entrega (cierre: 5 oct 2026, 4:00 p. m. CR)

## Registro
- [ ] Cuenta en Stellar Passport de cada integrante
- [ ] Inscripción en el hackathon
- [ ] Equipo creado en la plataforma (1 a 5 personas)
- [ ] Asistencia al encuentro presencial en el TEC (50 puntos)

## Producto
- [ ] Contrato(s) desplegado(s) en testnet, con ID anotado en el README
- [ ] App funcionando contra testnet
- [ ] Demo pública (URL) si es posible

## Repositorio (código abierto, obligatorio)
- [ ] Repo público en GitHub
- [ ] Licencia (MIT incluida)
- [ ] README con problema, solución, uso de Stellar, cómo correrlo e IDs de contratos
- [ ] Sin secretos en el historial

## Pitch
- [ ] Video de 3 minutos como máximo (problema, solución, cómo funciona, cómo usa Stellar)
- [ ] Subido con enlace público

## Formulario
- [ ] Nombre del proyecto
- [ ] Descripción
- [ ] Track: General Track
- [ ] Correo
- [ ] Enlace al repo
- [ ] Enlace al video
- [ ] Otros enlaces (demo, stellar.expert)
- [ ] Aceptar términos
